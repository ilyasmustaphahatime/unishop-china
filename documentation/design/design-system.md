# Design System

Phase 6 establishes a lightweight accessible component foundation: Button, Input, Textarea, Select, Card, Badge, generated Avatar, FormField, Spinner, Alert, EmptyState, and ProgressSteps.

The visual system uses UniShop red and white, neutral slate surfaces, modest gradients, 12–16px radii, clear focus rings, and restrained motion. Components use native semantic controls, associated labels, keyboard behavior, accessible status/alert roles, and responsive layouts.

Profile avatars are generated initials only. Phase 6 does not include file upload, remote avatar URLs, image processing, or cloud storage.
